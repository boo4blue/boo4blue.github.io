One-time setup

The site talks to your repo through GitHub's API, so it needs a key that can only touch boo4blue.github.io — nothing else.

  1. GitHub → your avatar → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access → Only select repositories → boo4blue.github.io
  3. Permissions → Contents → Read and write
  4. Generate token, copy it, paste below:

The key stays in this browser only (localStorage). No server ever sees it. You can revoke it anytime under the same Tokens page.
