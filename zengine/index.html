Our own game engine

Z Engine is a game engine written from scratch — no Unity, no Godot, no borrowed engine code. Renderer, physics, audio, particles, scripting: all hand-written, all ours.

Games, apps, and web views are all written in .Z files — one format for scenes and scripts. Write a .Z file, and Z Engine runs it.

One file does everything

# mygame.Z — a whole game in one file
scene "MyGame" {
    sky: sunset
    ground: desert
    prop hero {
        mesh: ball
        at: [0, 0.9, 0]
        body: sphere
    }
}

script {
    let hero = 0
    fn on_start() {
        hero = find("hero")
        play_sound("game_start")
    }
    fn on_tap(x, y, z) {
        let p = get_pos(hero)
        push(hero, (x - p[0]) * 3, 7, (z - p[2]) * 3)
        burst(p[0], p[1], p[2], 1, 0.8, 0.3, 20, 8)
    }
}

Engine systems

Renderer

Cel shading, ink outlines, fog, rim light, shader sky with sun, clouds, and stars. Borderlands-style painted textures.

Physics

Spheres and boxes, sequential impulses, friction, explosions, raycast picking. Our own solver.

Audio

SoundPool SFX. play_sound("explosion") from any script.

Particles

CPU point sprites. burst(x,y,z,r,g,b,count,speed) anywhere.

ZScript

Lua-flavored language with our own lexer, parser, and interpreter. Functions, arrays, callbacks.

Web

http_get(url) + on_http in scripts. open_z(url) loads .Z files from the web. Native webview widgets for apps.

Z Cloud

.Z files live in the cloud. The app fetches them by URL — publish a .Z file here and it runs on any Z Engine install. Muse controls the whole loop: write it, push it, play it.
