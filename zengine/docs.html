.Z Reference

One format for scenes, app UI, and scripts — single .Z files or multi-file projects.

Projects — Unity-style multi-file

Big games don't live in one file. A Z Engine project is a folder with separate scene and script files — just like Unity.

MyGame/
  project.Z              # manifest: name + entry scene
  Scenes/
    Main.Zscene          # scene "Main" { ... }
  Scripts/
    Player.Zscript       # script "Player" { attach: "hero" ... }
    Enemy.Zscript        # script "Enemy" { attach: "enemy1" ... }

project.Z — the manifest

project "MyGame" {
    entry: "Scenes/Main.Zscene"
}

Scripts attach to objects

Like Unity's components: a script with attach: "hero" runs for that prop. Inside it, self is the prop's name — so one script file can drive any object.

script "Player" {
    attach: "hero"   # self == "hero" in here

    fn on_update(dt) {
        let p = get_pos(self)
        move(self, p[0], p[1], p[2])
    }
}

Scripts without attach are global — they run for the whole scene, like a manager object. Each script is isolated (its own scope), and all scripts receive on_start, on_update, on_tap, on_http, on_ai.

Scene — 3D worlds

scene "MyWorld" {
    sky: sunset
    ground: desert
    prop crate1 {
        mesh: crate     # crate · ball · barrel
        at: [-4, 1, 0]
        body: box       # box · sphere
    }
}

Screen — app UI

screen "main" {
    label title {
        text: "Hello Z"
        at: [60, 120]
        size: 42
    }
    button play {
        text: "Play"
        at: [60, 400]
        size: [400, 110]
    }
    webview browser {
        at: [40, 600]
        size: [1000, 800]
        url: "https://example.com"
    }
}

Script — ZScript

Lua-flavored: fn · if/else · while · let · arrays · and/or/not

script {
    let score = 0
    fn on_start() { print("go!") }
    fn on_tap(x, y, z) { spawn("crate", x, 8, z) }
    fn on_click(id) {
        if (id == "play") { show_screen("game") }
    }
    fn on_ai(text) { hud_text(text) }
}

Callbacks

CallbackFires when
on_start().Z loaded
on_update(dt)every frame
on_tap(x, y, z)tap on 3D space
on_click(id)UI button tapped
on_http(url, body)web fetch returns
on_ai(text)AI answers

Game API

CallDoes
spawn(mesh,x,y,z)spawn prop → id
find("name")id by prop name
move(id,x,y,z)teleport
push(id,dx,dy,dz)add velocity
get_pos(id)[x, y, z]
freeze(id) / unfreeze(id)toggle physics
explode(x,y,z)explosion + FX + sound
burst(x,y,z,r,g,b,n,s)particles
play_sound(name,vol)SFX
hud_text(t)on-screen text
