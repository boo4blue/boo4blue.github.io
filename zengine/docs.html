.Z File Reference

A .Z file holds scenes (3D worlds), screens (app UI), and scripts (game logic) — all in one file.

Scene block — 3D worlds

scene "MyWorld" {
    sky: sunset
    ground: desert

    prop crate1 {
        mesh: crate      # crate, ball, barrel
        at: [-4, 1, 0]   # x, y, z
        body: box        # box or sphere (physics shape)
    }
}

Screen block — app UI

screen "main" {
    label title {
        text: "Hello Z"
        at: [60, 120]
        size: 42          # font size for labels
    }
    button play {
        text: "Play"
        at: [60, 400]
        size: [400, 110]  # width, height for buttons
    }
    webview browser {
        at: [40, 600]
        size: [1000, 800]
        url: "https://example.com"
    }
}

Script block — ZScript

Lua-flavored: fn, if/else, while, let, arrays, and/or/not.

script {
    let score = 0

    fn on_start() {
        print("go!")
    }

    fn on_update(dt) {
        score = score + dt
    }

    fn on_tap(x, y, z) {
        spawn("crate", x, 8, z)
    }

    fn on_click(id) {
        if (id == "play") {
            show_screen("game")
        }
    }

    fn on_http(url, body) {
        print("web says: " + body)
    }
}

Callbacks

CallbackWhen
on_start().Z file loaded
on_update(dt)every frame (dt in seconds)
on_tap(x, y, z)tap on empty 3D space (world coords)
on_click(id)app UI button tapped
on_http(url, body)http_get response arrived

Game API

FunctionWhat it does
spawn(mesh, x, y, z)spawn crate/ball/barrel, returns id
remove(id)delete entity
find("name")entity id by prop name
move(id, x, y, z)teleport entity
push(id, dx, dy, dz)add velocity
get_pos(id)[x, y, z]
freeze(id) / unfreeze(id)toggle physics
explode(x, y, z)radial explosion + FX + sound
burst(x,y,z,r,g,b,count,speed)particle burst
play_sound(name, vol)play SFX
count()entity count
time()seconds since boot

App + Web API

FunctionWhat it does
show_screen("name")switch app screen
set_text(id, text)update label/button text
open_z(file_or_url)load another .Z (local or http)
open_url(id, url)load URL into a webview widget
http_get(url)fetch URL, calls on_http
print(...)log to console
