Starter Bundles — six complete games

Every bundle is a full, playable game built entirely from presets: maps, mobs, NPCs, items, wheels and rules included. Load one, change anything, run it. This is how a new GM reaches a live session in under 30 minutes.

What's inside every bundle

A playable map or board · a cast of NPCs and mobs with dialogue sets · an item and shop economy · at least one weighted wheel · a rules pack built from templates · win/lose conditions and an end-of-game summary · a guided five-step setup checklist. Bundles reference presets by stable ID, so a catalog update never silently changes a published game — editing a preset forks a game-local copy.

Map Explorer — Forest Crossroads

Freeform map mode: the same presets, placed on a grid. Click any tile to inspect it. Fog hides what you haven't unlocked; a Watchtower reveals nearby spaces.

How maps work

Three movement models share one data model: connected spaces (board), grid, and freeform coordinates. Links can be one-way, two-way, locked, hidden, timed, toll, random or teleport. Collision, interaction range & unlocks are validated by the authoritative room in the full platform; this site validates them in-page.

Map kits included

Forest · Village · Dungeon · Cave · Marsh · Snow · Ruins · Horror · Festival · Coast — 10 kits, 18 playable templates from Village Square to Dragon Roost & Mirror Hall. Spaces support square, circle, star, hex, diamond and custom polygon shapes.

Preset Library

Every preset is more than an image: visual + metadata + gameplay defaults + states + editability, in three visual modes (board, map, portrait). IDs never change, so saved games never break. Search, filter, and add to your game.

Help, Guides & FAQ

Everything a GM or player needs: quick-start, the rules cookbook in plain language, safety and accessibility.

🎮 Player quick-start

Open the invite link or enter the game code (top of this page) → pick a display name and avatar → wait in the lobby → on your turn, roll, then click a space in range or move with W A S D / arrow keys → Interact to search, talk, shop or open things → manage items in your inventory and chat with the table. Joining takes under 30 seconds and needs no account.

📖 Rules cookbook — plain-language examples

“When a player holds the Crank for 3 seconds, and the Iron Gate is locked, unlock the Iron Gate, show ‘The gate groans open,’ and play the door-open effect.”
“When a player enters the Fog Marsh for the first time, spin the Weather Wheel.”
“When any player has the Broken Crown and all players are in the Throne Room, end the game as a win.”
“When the Wolf is defeated, and the player has fewer than 5 coins, give 2 coins; otherwise give a Fang.”

♿ Accessibility

Full keyboard play · screen-reader announcements for every state change · text alternatives and probability labels for wheels · non-colour cues for every player state · text scaling to 200% · reduced-motion mode swaps wheel spins for instant results · 44 px minimum touch targets · WCAG 2.2 AA target on all player screens.

Do players need an account?

No. GMs need an account; players join as guests with just a display name and can claim their profile later without losing game history.

Can the GM change a game while it's running?

Safe live edits (text, stats, item grants, reveal/hide) apply instantly. Structural edits — deleting a map, changing rules — require Pause, which auto-snapshots first, so a live session is never corrupted. You can also fork the game and edit the copy.

Are the wheels fair?

Yes — segment size equals probability, every draw is seeded and logged with its weights, and any session can be replayed from its log to verify outcomes. GMs get a deterministic test mode and optional reroll rules, never silent rigging.

What happens if a player disconnects mid-turn?

The turn timer continues; after a 60-second grace period the GM's chosen policy runs (skip, auto-pass, or wait). On return, the player resumes the current state within seconds — no duplicate actions, no replayed animations.

Can other players see my hidden items or stats?

No. Fog of war is computed per player and hidden entities are never sent to clients that aren't allowed to see them. Stat visibility is set per stat: everyone, owner + GM, or GM only.

Is there AI NPC dialogue?

It's post-launch, off by default, and opt-in per NPC with a per-game token budget. The AI only ever sees the NPC's persona and facts the GM marks shareable — never hidden game state — and any failure falls back to scripted dialogue.

How is the community kept safe?

Games are private and invite-only by default. Chat has mute, block, report and GM removal; uploads are scanned and re-encoded; horror presets carry content-rating tags with neutral fallbacks; kids mode disables player DMs and uploads.

Can I take my game with me?

Yes — export any game as a single .bgproj project file (game JSON + referenced assets + manifest) and import it elsewhere. Deleting a game is a soft delete for 30 days.

What devices are supported?

Any modern browser — Chrome, Edge, Firefox, Safari, desktop and mobile. The player UI is mobile-first from 360 px; the editor is aimed at tablets and desktops. No native app needed.
